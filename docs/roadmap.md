# ASD Roadmap

This roadmap defines the planned development path for Adaptive Semantic Deception.

ASD is currently maintained as a research architecture and conceptual active-defense framework.

---

## Phase 1 — Public Architecture Foundation

Status: in progress

Goals:
- define the public ASD architecture
- document core concepts
- establish licensing and repository structure
- describe ProjectionWorld, ObserverModel, and DecisionTrace
- clarify defensive scope and non-offensive intent

Outputs:
- README
- LICENSE
- STATUS
- architecture documentation
- core concept definitions
- initial threat model

---

## Phase 2 — Semantic Consistency Model

Status: planned

Goals:
- define ProjectionWorld consistency requirements
- model semantic continuity across interactions
- identify projection drift conditions
- define artifact lifecycle rules
- describe controlled imperfection principles

Expected outputs:
- semantic consistency document
- artifact lifecycle model
- projection drift notes
- basic consistency scoring proposal

---

## Phase 3 — Observer-State Simulation

Status: planned

Goals:
- create a minimal simulated observer

- test interaction pacing

Expected outputs:
- observer-state model
- simulation scenario

## Phase 4 — Minimal Runtime Prototype

Status: planned

Goals:
- implement minimal ASD runtime components

- log DecisionTrace

Minimal runtime components:

Status: planned

## Phase 6 — Integration Research

Status: future

---

## Long-Term Direction

The long-term goal of ASD is to explore whether active semantic defense can provide measurable defensive value by:

- shaping observer assumptions
- preserving coherent projection environments
- delaying hostile progression
- consuming adversarial attention
- extending defensive reaction windows
- maintaining auditability and safety boundaries

ASD will remain focused on controlled defensive environments and research-oriented active defense.
